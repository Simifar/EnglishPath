# Участие в разработке CortexMap

Спасибо за желание улучшить проект. CortexMap принимает исправления интерфейса, доступности, документации и каталога легальных материалов для изучения английского.

## Перед началом

- Для небольшой правки можно сразу открыть pull request.
- Для нового раздела или изменения модели данных сначала создайте issue и кратко опишите задачу.
- Не включайте в issue, коммиты и примеры секреты или персональные данные.
- Сохраняйте текущие `id`, `slug` и опубликованные URL. Название материала можно исправить без изменения его идентификатора.

## Требования к материалам

Добавляйте только официальные или иные законно распространяемые источники. Нельзя добавлять файлы учебников, способы обхода платного доступа, сомнительные зеркала и ссылки на пиратские копии.

Описание должно быть авторским, конкретным и нейтральным. Не копируйте большие фрагменты с сайта источника. Не утверждайте, что ресурс бесплатный, доступен без регистрации или подходит определённому CEFR, если это не подтверждено. Неизвестные сведения оставляйте в предусмотренном моделью состоянии `pending` или `unassessed`.

Структура записей и правила связей описаны в [docs/content-model.md](docs/content-model.md).

## Локальная разработка

```bash
bun install --frozen-lockfile
bun run dev
```

Интерфейсные строки пишутся на русском, код и комментарии — на английском. Используйте App Router, алиас `@/*` и существующие общие компоненты. Client Components нужны только для взаимодействий с браузером.

## Проверка изменений

Перед pull request выполните:

```bash
bunx tsc --noEmit
bun run lint
bun test
bun run validate-content
bun run build
```

Если изменение затрагивает статическую публикацию, дополнительно выполните:

```bash
bun run build:pages --base-path /EnglishPath --site-url https://example.github.io/EnglishPath/
bun run check:pages
```

В pull request объясните проблему, итоговое поведение и выполненные проверки. Для визуальных изменений приложите снимки экрана на десктопе и телефоне.
