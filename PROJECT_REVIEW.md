# Технический обзор CortexMap

Дата: 9 сентября 2026. Анализ текущей локальной копии EnglishPath.

## Назначение и границы

Русскоязычный справочник материалов по английскому: планы CEFR, экзамены, учебники, внешние ресурсы, поиск и локальное избранное. Нет БД, API приложения, аккаунтов, оплаты, тренажёров или отслеживания прогресса. Следует сохранять этот продуктовый фокус и ссылки только на легальные источники.

## Архитектура

- Next.js App Router; установлены Next 16.1.3, React 19.2.3, Bun 1.3.14. Версии package.json заданы диапазонами, воспроизводимость обеспечивает bun.lock.
- TypeScript, Tailwind CSS 4, Lucide; Zod проверяет каталог при импорте src/data/index.ts.
- src/app: маршруты и метаданные. Детальные страницы используют generateStaticParams и notFound.
- src/components/layout: шапка, подвал, контейнер, Breadcrumbs. Файлы SiteHeader/SiteFooter в catalog являются реэкспортами.
- src/components/content: общая карточка, её варианты, внешние ссылки, теги, иконки CEFR и JSON-LD.
- src/components/catalog: формы поиска и фильтров, избранное. Формы работают через URL и GET; клиентский код приложения сосредоточен в избранном.
- src/lib/search.ts: индекс в памяти, поиск по подстрокам, AND для слов запроса, ранжирование по заголовку/описанию/дополнительным полям. Морфологии, нечёткого поиска и пагинации нет.
- src/lib/catalog-filters.ts: нормализация query parameters и допустимых значений.
- src/hooks/useFavorites.ts: localStorage, ключ cortexmap:favorites.
- src/lib/site.ts: общий URL из NEXT_PUBLIC_SITE_URL с fallback https://cortexmap.ru. Значения .env не читались.

## Карта маршрутов

| Маршрут | Назначение | Режим текущей сборки |
| --- | --- | --- |
| / | Главная | Статический |
| /plans, /exams | Каталоги | Статический |
| /plans/[level], /exams/[exam] | Планы и экзамены | SSG |
| /textbooks, /resources | Каталоги с фильтрами | Серверный по запросу |
| /textbooks/[slug], /resources/[slug] | Детальные карточки | SSG |
| /search | Поиск и фильтры | Серверный по запросу |
| /favorites | Локальное избранное | Статическая оболочка + клиент |
| /opengraph-image | Социальное изображение | Динамический edge |
| /robots.txt, /sitemap.xml | SEO | Статический |

Это сайт со статическим контентом, но не полностью статический экспорт: требуется сервер Next.js. Build сохраняет standalone, копирует .next/static и public; команда успешно работает через Bun на этой Windows-машине.

## Данные

6 уровней, 88 тем, 22 записи учебников, 20 ресурсов, 3 экзамена. Всего 139 элементов поискового индекса.

Фактический исходник большей части каталога — legacyLevels и legacyWebsites в src/data/levels.ts. textbooks.ts и resources.ts преобразуют старые записи в новые модели. Добавление самостоятельных объектов в эти файлы по примеру README не соответствует существующему конвейеру.

Важные последствия:
- ID/slug книг и ресурсов вычисляются из заголовка. Переименование меняет URL и ломает старые ссылки и избранное.
- Учебники создаются отдельно для уровней; повторные издания/одна серия могут быть отдельными сущностями.
- Всем ресурсам автоматически присвоены все шесть уровней CEFR.
- Доступ ресурсов сводится из boolean к free/paid, хотя новая модель допускает mixed.
- Даты проверки массово заданы одной константой 2026-08-13; успешная Zod-валидация не подтверждает редакционную проверку.
- Издатель, серия и формат книг определяются эвристиками.
- Zod проверяет структуру, уникальность каталогов и ссылки textbookIds. Глобальная уникальность тем между уровнями не проверяется; URL не ограничен HTTP(S). TypeScript и Zod частично расходятся по verifiedAt у Topic и ExamGuide.

## Проблемы по приоритету

### Высокий: избранное теряет изменения

Каждый useFavorites имеет независимый useState и читает хранилище только при монтировании. Если нажать две разные карточки на одной странице, вторая записывает свой устаревший массив и может стереть первую. FavoritesList не получает обновление при удалении через вложенную FavoritesButton, поэтому строка и счётчик остаются до перезагрузки. Нет подписки на storage или общие события; запись localStorage не защищена try/catch. Вывод подтверждён логикой кода, браузерное воспроизведение в рамках обзора не выполнялось.

Направление исправления: единое хранилище с подписками, синхронизация внутри страницы и между вкладками, безопасная запись, явное состояние загрузки.

### Средний: поиск скрывает часть результатов

src/app/search/page.tsx обрезает выдачу slice(0, 30), затем показывает длину обрезанного массива как «Найдено». Запрос «грамматика» даёт 46 совпадений в функции поиска, но HTTP-страница показывает 30 и не позволяет открыть остальные. Ссылки тем ведут на начало плана без якоря конкретной темы.

### Средний: цвет карточек не генерируется

В globals.css объявлен --card, но в @theme отсутствует --color-card. Проверка production CSS показала отсутствие .bg-card, хотя класс используется на главной и карточках. Старый tailwind.config.ts содержит иное описание цветов и импорт отсутствующей в package.json зависимости tailwindcss-animate; файл не подключён через @config. Нужен единый актуальный набор токенов Tailwind 4.

### Средний: конфликт robots и непоследовательное SEO

Одновременно существуют public/robots.txt и src/app/robots.ts. Запрос к standalone-серверу вернул содержимое public: без Sitemap и без ограничения /search. Sitemap при этом включает /search, хотя страница имеет noindex. lastModified всех страниц жёстко задан одной датой. У главной заголовок уже содержит CortexMap, а layout добавляет бренд шаблоном. Метаданные Open Graph/Twitter стоит согласовать для внутренних страниц.

### Средний: проверка внешних ссылок ненадёжна как единственный CI-барьер

check-external-links завершился на втором адресе: Cambridge /face2face вернул HTTP 530. Это сбой доступности при автоматическом запросе, не доказательство битой ссылки. Скрипт останавливается на первой ошибке, не собирает общий отчёт, повторяет одинаковые адреса, пропускает YouTube и не проверяет ссылки тем, уровней и officialMaterials отдельно. HEAD заменяется GET только при 405. CI запускает этот сетевой шаг перед build, поэтому внешний сбой блокирует последующие проверки.

### Контент и интерфейс

- В A1 есть текст «Уметь填写 простые формы».
- На карточках/страницах ресурсов выводятся английские category-коды; есть английские служебные надписи каталогов.
- Подпись «Только бесплатные» в фильтрах включает mixed: нужно определить семантику.
- Всем ресурсам присвоен диапазон A1–C2, поэтому фильтр уровня не различает их.
- Данные используют оценочные описания и сроки без конкретной нагрузки. Предметную точность CEFR, экзаменов, авторов, изданий и условий доступа нужно проверять отдельным редакционным проходом.
- Header/Footer повторяются в страницах; вынесение в общий layout уменьшит расхождения.
- Существуют неиспользуемые/наследованные элементы, например Breadcrumbs и старая конфигурация Tailwind.
- Большинство компонентов записано одной длинной строкой, что затрудняет ревью.

## Проверки и эксплуатация

Успешно: bunx tsc --noEmit; bun run lint; bun run validate-content; bun run build; bun run check-bundle. Последний проверил 11 JS chunks с лимитом 400 KiB на файл, а не общий объём страницы или сжатый размер.

Production-сервер запущен для проверки на порту 3100. Все 51 детальные страницы и семь основных страниц вернули 200; неизвестный маршрут и /plans/unknown — 404. Запросы фильтрованных каталогов и поиска — 200. Проверены реальные Cache-Control: публичные каталоги — сутки s-maxage, поиск — 300 секунд, избранное — private/no-store.

Запрос /opengraph-image не завершился в период наблюдения; успешность этого маршрута не подтверждена. Визуальная проверка в браузере, Lighthouse, нагрузочное тестирование, аудит зависимостей по базам уязвимостей и полный фактчекинг источников не выполнялись.

ESLint имеет много отключённых проверок; noImplicitAny=false ослабляет strict TypeScript. lint охватывает только src, а scripts и корневые конфигурации не входят в текущий TypeScript include. Нет автоматических функциональных тестов. Lighthouse настроен, но не включён в workflow.

Caddyfile слушает :81 и позволяет выбирать localhost-порт параметром XTransformPort. Если этот конфиг используется на публичном сервере без внешних ограничений, клиент может направлять запросы к другим локальным сервисам. Перед публичным применением необходимо определить назначение этого механизма и ограничить разрешённые upstream. В этом обзоре Caddy не запускался.

В текущей папке отсутствует .git: историю, ветки и diff проверить нельзя. Код приложения не изменялся; добавлен только этот обзор, проверки обновили генерируемые артефакты.
