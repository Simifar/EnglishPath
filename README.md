# CortexMap

Русскоязычный справочник для самостоятельного изучения английского: планы CEFR A1–C2, учебники, экзамены, внешние ресурсы, поиск и локальное избранное.

В проекте нет регистрации, базы данных, личных кабинетов и тренажёров. Материалы хранятся в src/data. На сайте опубликованы собственные описания и ссылки на легальные источники, без копий учебников.

Статус: рабочий пет-проект. Редакционная проверка каталога ещё продолжается; непроверенные сведения отмечены на страницах.

## Запуск

Нужен Bun 1.3.14 (эта версия закреплена в GitHub Actions).

```sh
bun install --frozen-lockfile
bun run dev
```

Сайт откроется на http://localhost:3000. Файл .env для запуска не обязателен; пример публичных настроек — .env.example.

## Проверки

```sh
bun test
bunx tsc --noEmit
bun run lint
bun run validate-content
bun run build
bun run check-bundle
```

Тесты проверяют избранное, поиск, фильтры, совместимость адресов и модель данных. Проверка внешних сайтов выполняется отдельно через bun run check-external-links или ручной workflow External links: временная блокировка стороннего сайта не останавливает публикацию.

## GitHub Pages

Подготовлена полностью статическая сборка. Страницы генерируются заранее, поиск и фильтры работают в браузере с параметрами в URL. Для работы сайта не нужны сервер Next.js, Neon, Vercel или платные ключи.

Проверка варианта с префиксом репозитория:

```sh
bun run build:pages --base-path /EnglishPath --site-url https://example.github.io/EnglishPath/
bun run check:pages
bun run preview:pages
```

Откройте http://127.0.0.1:4173/EnglishPath/. Команда preview обслуживает готовые файлы без серверного рендеринга и без перенаправления всех адресов на главную.

Полная инструкция первого push, включения Pages и собственного домена: [docs/github-pages.md](docs/github-pages.md).

Workflow GitHub Pages публикует папку out после push в main или ручного запуска. Адрес сайта и префикс репозитория получает из настроек GitHub Pages автоматически. Локальные .env, out и node_modules не входят в Git.

## Другой хостинг

Сохранён прежний standalone-режим:

```sh
bun run build
bun run start
```

Build копирует .next/static и public в standalone. Caddyfile относится только к самостоятельному серверу; GitHub Pages его не использует. Cache-Control из next.config.ts применяется к серверному режиму; на Pages заголовками управляет хостинг.

## Контент и устройство проекта

- src/app — страницы и метаданные.
- src/components/catalog — поиск, фильтры, избранное.
- src/components/content и layout — карточки и общий интерфейс.
- src/data — записи и Zod-схемы; ID и slug постоянны.
- tests — регрессионные проверки.
- scripts — валидация, сборка и просмотр статической версии.

[Как добавлять материалы](docs/content-model.md) · [План развития](ROADMAP.md).
